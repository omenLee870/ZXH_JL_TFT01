# 逐个检查实体按键

倒车切换现改用已验证可识别的 OK（KEY_AD_NUM1 / value=11）：在宠物仪表短按进入，再次短按返回。临时即时 ADC 探针默认关闭，保留按键事件诊断。

当前 `src/按键配置.json` 配置了 5 个 AD 按键，AD 输入为 `IO_PORTE_03`。
IO 按键、旋转编码器及触摸按键未启用。当前配置计算出的区间如下；板上实际
读取的配置以启动时 `[KEY_DIAG] AD table` 为准。

| 编号 | value | ADC 原始值区间 | 已知用途 |
| --- | --- | --- | --- |
| KEY_AD_NUM0 | 10 | 0～385 | 切屏 |
| KEY_AD_NUM1 | 11 | 386～1025 | OK，5.1kΩ，实测约 0.6V |
| KEY_AD_NUM2 | 12 | 1026～1615 | DOWN，10kΩ，实测约 1.0V |
| KEY_AD_NUM3 | 13 | 1616～2203 | UP，20kΩ，实测约 1.5V |
| KEY_AD_NUM4 | 14 | 2204～3276 | BACK 物理编号；倒车入口已改用 OK |

上述 DOWN/UP 名称按硬件手册及用户实测对应；独立参考原理图的这两个名称互换。
BACK 的 33kΩ 支路实测约 1.9V，与键值 14 的配置吻合。

诊断默认开启，完成后将 `key_driver.h` 的 `KEY_DIAG_ENABLE` 改为 `0`。
重新编译并烧录后，从开机开始保存串口日志。启动应出现：

- `AD configured_keys=5` 及 5 条 `AD table`：实际读到的按键配置。
- `driver_init type=1 ret=0`：AD 驱动初始化成功。
- `scan_timer ... id=` 与 `ADC monitor timer=`：非 0 表示定时器申请成功。

每个按钮单独按约 0.5 秒、松开，间隔 1 秒，按实体按钮顺序记录名称。
短按应出现 `event=DOWN`、`event=UP`、`event=CLICK`，三条日志的 `value`
应一致，`ad_index` 是 AD 编号。长按会出现 `LONG`；周期性 HOLD 不打印。
`driver` 是物理扫描驱动类型，`msg_type` 是原始事件结构的类型字段。
日志覆盖所有已注册的按键驱动，打印发生在转交 UI 之前。

`ADC` 每 200ms 检查一次；键值变化、ADC 相对上次打印变化至少 32 时输出，
空闲时每 2 秒输出心跳。此行原始值由原有扫描读取 ADC 队列缓存取得。
`mapped=-1` 表示该扫描未匹配任何按键，`scans` 是扫描次数。
`scans` 增加只证明扫描读取在运行，不能独立证明硬件 ADC 转换持续完成。

## 电压正常但队列缓存不跟随：即时采样对照

`KEY_DIAG_DIRECT_ADC_ENABLE` 默认是 `0`；需要重新诊断时设为 `1`。启用后监控在 app_core 的系统定时器中
每 200ms 使用 SDK 的 `adc_get_value_blocking()` 即时采集同一个通道一次，
并打印 `ADC_PROBE`；不在原有按键扫描中调用，不增加新的通道。
变化时打印，稳定时每 2 秒打印一次；单次耗时达到 20ms 时也会打印。

- `queued` / `queued_key`：即时采样前的 ADC 队列缓存及其键值。
- `direct` / `direct_key`：本次即时采样值及按现有阈值计算的键值。
- `queued_after`：即时采样返回后再读队列缓存。
- `probe_ms`：即时采样调用耗时；若 SDK 报 ADC 超时，应连同该报错一起分析。

诊断期间依次按 OK、DOWN、UP、BACK，每个持续约 2 秒，松开后间隔 3 秒。
本轮长按用于观察采样，不用于测试只接受短按 CLICK 的倒车入口。

- `direct_key=12/13/14`，而持续按住后 `queued_key` 仍为 `-1`：优先查 ADC
  队列更新或通道切换；刚按下/松开时单次不一致可能只是两次采样的时间差。
- 若即时采样和缓存都不跟随已测得的稳定电压：查 PE3 输入、ADC 通道及复用配置；
  不能据此直接断定芯片损坏。
- 若加探针后按键恢复：探针会重新选择采样通道，该现象提示检查复用或队列状态，
  不能把即时采样作为正式修复直接保留。

即时采样会暂时占用并重配 GPADC，可能影响原队列时序，是临时诊断探针。
将 `KEY_DIAG_DIRECT_ADC_ENABLE` 改成 `0` 可以单独关闭探针，保留原有按键日志。

- ADC 改变但一直 `mapped=-1`：检查该按钮的电阻、阈值及接线；日志不能独立
  区分这些原因。
- 有 `DOWN/UP/CLICK`，UI 没执行对应动作：继续查消息传递或页面映射。
- `scans` 持续增长但按键时 ADC 没有可见变化：检查实体按钮是否接到配置的
  ADC 输入；按满 0.5 秒避免短脉冲被 200ms 监控漏掉。
- `SCAN_STALLED` 或 `ADC no_samples`：检查扫描定时器是否运行。

按键阈值、消抖、事件结构和页面映射保持不变；即时探针的采样影响如上所述。
