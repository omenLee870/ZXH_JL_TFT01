# 旧版源码存档（v1.0）

当前上位机工程已迁至 `D:\omenLee_project\ZXH-TFT\380tft_1\上位机`，新版为模块画布界面。请在新目录运行 `app.py` 或 `dist/ZXH-Vehicle-Lab/ZXH-Vehicle-Lab.exe`；本目录仅保留第一版源码。

Windows 10/11 原生桌面软件，电脑模拟电动车控制器，与真实 TFT 仪表进行神龙锂电2号双向串口通信。界面中的车辆使用矢量绘制，支持车轮转动、车灯光束、刹车尾灯、转向闪烁、电池和电流动画。

## 快速开始

1. 打开 `ZXH-Vehicle-Lab.exe`，无需安装 Python。整个程序文件夹必须一起保留。
2. 未连接时可直接打开钥匙、调转把、切灯光、刹车、模拟故障和充电。
3. 仪表先使用本工程的神龙串口版固件。上位机无法直接与旧一线通固件收发 UART 数据。
4. 选择正确的 COM 口并点击连接，参数固定为 **9600 / 8数据位 / 无校验 / 2停止位**。
5. 连接不会自动发帧。打开软件钥匙开始发送控制器反馈，默认120ms一帧；关闭钥匙或勾选暂停发送可观察仪表掉线处理。
6. 默认“跟随真实仪表指令”：仪表开关、灯光和倒车命令控制虚拟车辆，命令1秒未更新时停止模拟驱动力。可取消跟随，手动注入控制器反馈。
7. 右侧可调轮径、电量、剩余里程、车速及故障；轮径必须和仪表一致，默认16.0英寸。关闭“根据转把模拟加减速”即可手动设定目标车速。
8. “收发监视”显示 HEX 和解析，保留最近300条可见记录；CSV 导出最近5000条，兼容 Excel 中文。仪表参数页显示最后有效命令，不代表当前仍在线。

## 接线

| USB转串口 | 仪表配置 |
| --- | --- |
| TX | PC05（仪表RX） |
| RX | PC04（仪表TX） |
| GND | 仪表信号地 |

使用3.3V TTL，仪表单独按正常方式供电。PCB是否引出PC04/PC05需要对照实际板子确认。串口适配器的VCC不需要连接；RS232、RS485、5V信号和电池电压不能直接接入GPIO。原PA12仍是1000000波特率日志口，不是本协议通信口。

## 功能范围

| 功能 | 软件动作 | 真实仪表联动 |
| --- | --- | --- |
| 车速 | 车轮旋转、显示车速 | 发送轮周时间，仪表换算车速 |
| 电量/电流 | 数值及能量动画 | 协议反馈 |
| 刹车/充电/故障 | 动画/状态切换 | 协议反馈；当前仪表界面显示刹车和故障，充电位保留在报文中 |
| 大灯 | 光束及开关 | 跟随仪表发出的灯光总开关 |
| 助力等级 | 显示收到的0~15等级 | 当前仪表ECO/CITY/SPORT映射5/10/15 |
| 示廓灯/转向灯 | 本地动画 | 原协议无独立字段 |
| 钥匙 | 模拟供电状态、控制上位机发帧 | 不切断真实仪表电源；真实上下电需硬件 |
| 倒车 | 动画方向改变、模拟限速6km/h | 可接收仪表倒车命令；当前仪表界面尚无倒车命令入口，控制器反馈没有独立倒车位 |

上位机速度采用简化的加减速模型，并非整车动力学模型。转把是软件模拟的车辆输入；收到非零仪表PWM时优先使用该PWM。驱动方式、助力PWM、灵敏度等参数可在参数页观察，尚未实现完整助力踏频和控制器闭环模型。

协议电量0同时可能表示无BMS或0%电量，仪表端保守显示未知。反馈不包含电池电压、实际档位、大灯状态、钥匙状态，因此不伪造这些反馈。没有独立转向和示廓灯扩展协议。

## 从源码运行和验证

```powershell
python -m pip install -r desktop/vehicle_simulator/requirements.txt
python desktop/vehicle_simulator/app.py
powershell -ExecutionPolicy Bypass -File tools/TestShenlong.ps1
powershell -ExecutionPolicy Bypass -File tools/BuildVehicleSimulator.ps1
powershell -ExecutionPolicy Bypass -File tools/BuildShenlongFirmware.ps1
```

仪表构建只编译和链接，不运行下载脚本。板级配置文件 `SDK/apps/watch/board/br33/board_jl380n_demo/board_jl380n_demo_cfg.h` 中 `TCFG_SHENLONG_UART_ENABLE=1` 为串口版，改成0可回到一线通；也可用 `BuildShenlongFirmware.ps1 -OneWire` 构建一线通版。

SDK UART 没有停止位参数，仪表UART1使用恒1校验（8M1），线上8个数据位后连续两个高位，与8N2波形等价。该路径已编译，实际板子仍需逻辑分析仪确认9600波特率、8位数据和两个停止位，并确认无UART占用冲突。

界面使用Qt for Python / PySide6，串口使用pySerial。打包文件夹保留Qt运行库及随附许可证。
